# Twilio WhatsApp Sandbox for the Hawlak prototype

Use this transport when a Meta WhatsApp Business Account is pending review or
locked. It is a testing-only path: the AI, approval checksum, PostgreSQL audit
trail, ElevenLabs audio and Hawlak-isolated MinIO storage remain unchanged.

## What the adapter supports

- two OGG/Opus Arabic discharge voice notes generated by ElevenLabs;
- an audio-guided `١/٢` reminder followed by the patient's stored photo;
- numeric quick replies mapped to `taken` and `not_yet`;
- signed Twilio status callbacks;
- inbound text and medicine-box photos;
- authenticated image download and private MinIO storage;
- short-lived, HMAC-signed public media URLs for Twilio to fetch audio.

Meta credentials remain in `.env` for later, but the provider switch ensures
that one rehearsal uses only one WhatsApp transport.

## Activate and join the Sandbox

1. Sign in to <https://console.twilio.com/>.
2. Open **Messaging → Try it out → Send a WhatsApp message**.
3. Activate the testing environment if prompted.
4. From the demo phone, scan the QR code or send the displayed
   `join <sandbox-code>` message to the displayed Sandbox number.
5. Copy the Account SID, Auth Token and the exact displayed Sandbox sender
   number. Trial environments can use a number other than `+14155238886`.

## Save configuration without printing secrets

Run from the repository root. Replace only the public URL and Sandbox number;
the two credential prompts are hidden.

```bash
cd /Users/haya/Documents/ChatGPT/medathon/hawlak-mvp

read "TWILIO_SID?Paste Twilio Account SID: "
read -s "TWILIO_TOKEN?Paste Twilio Auth Token: "
echo
read "TWILIO_FROM?Paste Sandbox number with + and country code: "

/Users/haya/.cache/hawlak-api-venv/bin/dotenv -f .env set \
  TWILIO_ACCOUNT_SID "$TWILIO_SID" >/dev/null
/Users/haya/.cache/hawlak-api-venv/bin/dotenv -f .env set \
  TWILIO_AUTH_TOKEN "$TWILIO_TOKEN" >/dev/null
/Users/haya/.cache/hawlak-api-venv/bin/dotenv -f .env set \
  TWILIO_WHATSAPP_FROM "$TWILIO_FROM" >/dev/null
/Users/haya/.cache/hawlak-api-venv/bin/dotenv -f .env set \
  WHATSAPP_PROVIDER twilio >/dev/null

unset TWILIO_SID TWILIO_TOKEN TWILIO_FROM
echo "Twilio Sandbox configuration saved"
```

Set `PUBLIC_BASE_URL` to the current HTTPS Cloudflare tunnel origin, without a
path. In Twilio's inbound settings, choose **Custom**, use HTTP POST, and enter:

```text
https://<temporary-host>/webhooks/twilio
```

The same route accepts inbound messages and outbound delivery callbacks.
Twilio fetches approved audio from:

```text
https://<temporary-host>/webhooks/twilio/media/<short-lived-signed-token>
```

The public webhook app exposes no `/internal/*` routes and the MinIO bucket
remains private.

## Rehearsal

Restart both API processes after changing `.env`. Send any message from the
joined phone to the Sandbox immediately before the rehearsal to open the
24-hour customer-service window. Run the controlled live demo and approve the
exact generated checksum. Confirm the phone receives two Arabic OGG/Opus
notes. The first contains the spoken AI disclosure, medicine summary and photo
request; the second contains recovery instructions and warning signs.

Send synthetic medicine-box photos. Hawlak downloads them with Twilio Basic
authentication, stores opaque bytes and checksums in its own MinIO bucket, and
emits the pharmacist-review event after the expected count.

## Sandbox branding versus a Hawlak sender

The Sandbox uses a shared Twilio number and always displays Twilio's logo. Its
name, photo and number cannot be customized. Keep it for the judge demo.

To use a Hawlak profile photo, display name and dedicated phone number, register
a WhatsApp sender through Twilio Self Sign-up. The number can be a Twilio or
non-Twilio number, but it must receive an SMS or voice OTP and must not still be
active in the consumer WhatsApp apps.

Run the repeatable setup wizard from the repository root:

```bash
./scripts/setup_live_demo.sh
```

It uses
[`hawlak-whatsapp-profile.png`](../design-system/assets/hawlak-whatsapp-profile.png),
walks through Self Sign-up and profile configuration, then writes the sender,
credentials, provider switch and public webhook origin to `.env` without
printing the Auth Token.
